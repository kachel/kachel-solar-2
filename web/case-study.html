Designing the Sticker Weather website

Why did you make this?
  1. I wanted to upcycle my old tablet into a customizable dashboard
  2. Weather apps do not have the information I want to see at a glance

Air Quality Index being the most important after all the wildfire smoke we've been getting in the Midwest. As well as UV Index, gotta wear your sunscreen.

How did you make this?

I started by using Claude to do an initial exploration on weather APIs. I wanted to make sure they did not need any keys and had global information.

Once I had some sample JSON, I went to Figma to design out two main areas: the canvas where the stickers live and the sticker sheet drawer.

After the layouts were done, I got to work on my favorite part of the process: the stickers!! I had so much fun designing the sun conditions with their little faces.

Lastly, I used AI to code it into reality. The prototype became a shareable website.

tl;dr Sample JSON -> Wireframes -> Figma mockups and assets creation -> Claude Code

The website is AI-assisted, what did you do vs what did Claude do?

I designed the layouts, created the sticker assets, and dictated all of the functionality. Claude implemented the API code and website code. After implementation, I did the QA and bug catching.
