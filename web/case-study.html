Designing the Sticker Weather Website

Why did you make this?
  1. I wanted to upcycle my old tablet into a customizable dashboard
  2. Weather apps do not have the information I want to see at a glance
How did you make this?

I started by doing an initial exploration on weather APIs. I wanted to make sure they did not need any keys and had global information.

Once I had some sample JSON, I went to design the two main spaces: the canvas where the stickers live and the sticker sheet drawer.

After the layouts were done, I got to work on my favorite part of the project: the stickers!! I had so much fun designing the sun conditions with their little faces.

Lastly, I used AI to code it into reality. The prototype became a shareable website.

tl;dr: Sample JSON -> Wireframes -> Figma mockups and assets creation -> Claude Code

What did you do vs. what did the AI do?

I designed the layouts, created the sticker assets, and dictated all of the functionality. Claude implemented the API and website code. After implementation, I did the QA and bug catching.
